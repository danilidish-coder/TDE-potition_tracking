# TDE Position Tracking

Windows εφαρμογή **Καταγραφή Θέσεων** για το Τ.Δ.Ε. Κρυσταλλοπηγής.

## Για απλή χρήση
Μην ψάχνεις στους φακέλους του repository.

1. Άνοιξε **Releases**.
2. Άνοιξε την έκδοση με ένδειξη **Latest**.
3. Στα **Assets** κατέβασε μόνο το **TDE_Katagrafi_Theseon.exe**.

Το **Source code** που εμφανίζει αυτόματα το GitHub δεν είναι το πρόγραμμα για χρήση.

## Τι βρίσκεται πού
- `src/position_tracking.py` — ο πραγματικός πηγαίος κώδικας.
- `tests/` — αυτοματοποιημένοι έλεγχοι.
- `release/Καταγραφή Θέσεων.exe` — το τελευταίο επιβεβαιωμένο Windows EXE.
- `.github/workflows/` — build και δημοσίευση έκδοσης.
- `VERSION.txt` — έκδοση που δημοσιεύεται στα Releases.
- `DEVELOPMENT_RULES.md` — μόνιμοι κανόνες αλλαγών.

## Κανόνας εκδόσεων
- Το `main` είναι η σταθερή πηγή αλήθειας.
- Οι νέες αλλαγές δοκιμάζονται πρώτα σε `feature/*` branch.
- Στο `release/` κρατάμε μόνο το τελικό EXE.
- Τα προσωρινά/test EXE παραμένουν μόνο ως GitHub Actions artifacts.
- ZIP δημιουργείται μόνο όταν ζητηθεί ρητά.

## Τρέχουσες λειτουργίες
Η βασική λειτουργία Καταγραφής Θέσεων και διαχείρισης βάρδιας παραμένει αμετάβλητη. Οι πρόσθετες λειτουργίες συντηρούνται χωρίς αλλαγή της επιχειρησιακής λογικής.
