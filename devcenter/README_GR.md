# Πιλοτική υποδομή Κέντρου Προγραμματισμού (GitHub)

**Προστασία παραγωγής:** αυτός ο κλάδος είναι μόνο δοκιμαστικός. Δεν ενημερώνεται το `main`, δεν αλλάζει το υπηρεσιακό EXE και δεν δημιουργείται παραγωγικό release.

## Κοινή διαδικασία

Η δομή `devcenter/qa.json` περιγράφει όλες τις υποχρεωτικές δοκιμές και την εντολή κατασκευής EXE. Η `devcenter/qa_gate.py` τις εκτελεί μία προς μία σε Windows/Linux, γράφει τις πραγματικές εξόδους και ελέγχει ότι όλες ολοκληρώθηκαν επιτυχώς.

1. **TEST:** Εκτελούνται αυτοματοποιημένα και stress tests. Όσα δεν ισχύουν στο εκάστοτε λειτουργικό καταγράφονται ρητά.
2. **GATE:** Αποτυχία, timeout, σφάλμα εκκίνησης ή έλλειψη tests αποδίδει μη μηδενικό exit code και αποτέλεσμα FAIL.
3. **BUILD:** Μόνον εάν όλα τα υποχρεωτικά τεστ πέρασαν στο ίδιο τρέξιμο και πρόκειται για Windows, παράγεται το EXE.
4. **REPORT:** Παράγονται `devcenter_reports/qa_windows.json`, `qa_linux.json` και κείμενο ανά σύστημα. Τα συμπεράσματα εμφανίζονται και στο GitHub Actions Job Summary.
5. **NO RELEASE:** Ακόμη και με PASS, η δοκιμαστική υποδομή δεν δημοσιεύει παραγωγική έκδοση.

Περιλαμβάνεται **σκόπιμα ερυθρή δοκιμή** για τον γνωστό παλιό ΑΓΜΣ μετά από απορριφθείσα ασυμφωνία στη v1.2.5. Η αποτυχία αυτής της δοκιμής σημαίνει ότι το σύστημα **λειτουργεί σωστά ως φραγμός έκδοσης**, όχι ότι πρέπει να δημοσιευθεί EXE.

Για τοπική χρήση **χωρίς σύνδεση στο GitHub**:

`python devcenter/qa_gate.py test --config devcenter/qa.json`

ή στα Windows (εφόσον έχουν εγκατασταθεί οι εξαρτήσεις):

`python devcenter/qa_gate.py full --config devcenter/qa.json`

Οι εντολές Python, Go, PyInstaller ή άλλων εργαλείων εκτελούν κώδικα. Μη χρησιμοποιείτε ZIP/πηγαίο κώδικα αγνώστου προέλευσης χωρίς απομόνωση. Για απόρρητα έργα, το ZIP, ο πηγαίος κώδικας και οι αναφορές παραμένουν μόνο στον προσωπικό υπολογιστή: καμία εντολή αυτού του manifest δεν ανεβάζει δεδομένα.

**Όριο κάλυψης:** οι προσομοιώσεις 15 σταθμών δεν υποκαθιστούν πραγματικό 15-σταθμών SMB δικτυακό έλεγχο ούτε φυσική επανεκκίνηση των υπολογιστών.
